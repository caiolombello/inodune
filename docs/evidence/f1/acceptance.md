# Fase 1 — evidências em andamento

- Scanner real Rust e CLI/GUI compartilhados, sem executor. O modo desktop começa local, sem medição e sem scan automático; modo demo mantém corpus sintético separado.
- `cargo clippy --locked --workspace --all-targets -- -D warnings` passou incluindo shell nativo; typecheck/lint/Vitest/build passaram nos incrementos verificados.
- Testes read-only geram apenas árvores temporárias: symlink externo, raiz trocada, overlap, hardlink, formato desconhecido, Python compilado em fixture, Terraform/IA protegidos, limites e cancelamento.
- Bind mount efetivamente testado em user+mount namespace privado (`cargo test -p inodune-core --test scan refuses_bind_mounts -- --ignored --nocapture`): passou. Não houve mount no namespace do host nem sudo nesse teste. Mantido ignored no runner padrão por exigir suporte explícito do kernel/CI.
- Native E2E: `cargo build -p inodune-desktop --features fixture-tests` + `python3 scripts/native-e2e.py` passou com WebKitGTK real, Tauri IPC e scanner real. O app de teste cria suas próprias roots temporárias; feature está ausente da configuração padrão de produção. Confirma volume inicial não inventado, seleção conservadora, inventário de IA/estado e rejeição de `/etc` usado como ID forjado, sem escaneá-lo. Capturas em `../native-f1/`.
- tauri-driver 2.1.0 instalado apenas em `.tools/`. WebKitWebDriver 2.54.2 foi extraído de RPM oficial Fedora com assinatura validada, sem instalar outro engine. O servidor de testes escuta loopback e é encerrado com seu Xvfb/Vite próprios. Ver fonte oficial: https://v2.tauri.app/develop/tests/webdriver/manual-setup/ .
- Chromium: 10 testes E2E passaram (7 jornadas + 3 volumes de lista), usando o build de produção. Benchmarks do renderer 100/1000/10000 têm JSON próprio neste diretório: fixtures IPC sintéticas, não prova de scan nativo ou 60fps. Listas grandes têm virtualização dinâmica e alternativa paginada/teclado; sem truncar o caminho no diálogo de revisão.
- Limitações explícitas: Git ainda é marcador protegido nesta fase; descoberta autoritativa de registros/status segue na F3. Leitor de tela real/Wayland/usabilidade com participantes não certificados. Nada foi apagado; futuros testes do executor também serão apenas em temporários.

- Standalone: `npm run desktop -- build --debug --no-bundle --features fixture-tests` seguido de `INODUNE_NATIVE_STANDALONE=1 python3 scripts/native-e2e.py` passou sem Vite em execução. Assets SVG foram verificados sob CSP restrita; foi corrigido um bloqueio de data: images usando assets locais, sem afrouxar a CSP. Capturas em `../native-f1-standalone/`. Isto prova standalone debug com fixtures; não é release/pacote assinado.
